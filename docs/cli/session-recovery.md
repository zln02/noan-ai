# 데스크톱 CLI — 세션 찾기 / 없으면 다시 익히기

## 1. 먼저 세션이 남아 있는지 본다

Claude Code 세션은 **폴더별**로 저장된다. 저장소 폴더에서 열어야 보인다.

```bash
cd <noan-ai 저장소 폴더>
claude --resume
```

목록이 뜨면 `noan` · `덱` · `안내서` 같은 제목을 찾아 고른다.
**목록이 비어 있거나 관련 없는 것만 있으면 → 맥북에서 한 세션이다. 데스크톱엔 없다.** 2로 간다.

## 2. 없으면 — 새로 열고 아래를 그대로 붙여넣는다

```bash
claude
```

```
너는 노안중학교 AI교육 코디네이터 박진영의 사이트 zln02/noan-ai 를 만드는 CLI다.
이전 세션이 다른 컴퓨터에 있어서 여기엔 기억이 없다. 작업 전에 먼저 익혀라.

읽을 것 — 이 순서로:
1. git log --oneline -40        ← 무엇이 언제 됐는지
2. CLAUDE.md, tools/CONTRACT.md ← 있으면. 지켜야 할 규칙
3. docs/ 안의 .md 전부          ← 매뉴얼 분석, 원고 기록본
4. README.md
5. shared/tokens.css, shared/deck.css, training/s1.html 의 구조 (내용 말고 골격)
6. 방금 받은 bundle/READ-ME-FIRST.md ← 오늘 할 일과 우선순위

다 읽고 나서 아래 여섯 줄을 네 말로 요약해서 보고해라. 그 전엔 아무것도 고치지 마라.
- 이 사이트의 목적 한 줄
- 연수 덱은 몇 장이고 어떤 id 순서인가
- 절대 규칙 (오프라인 · private/ · 원고 불변 · 토큰 색 · 외부 라이브러리)
- 마지막 커밋 5개가 각각 무엇을 했나
- bundle/READ-ME-FIRST.md 기준 오늘 할 일 순서
- 네가 확실하지 않은 것

요약이 맞으면 진영님이 "시작" 이라고 한다. 그때 READ-ME-FIRST A-1 부터.
```

## 3. 확인할 것

CLI 요약에 아래가 빠져 있으면 다시 읽으라고 해라.

- 덱이 **24장**이고 `s4·s5`가 일부러 없다는 것
- `guide/` 가 **아직 없다**는 것 (3f 미실행)
- `private/` 커밋 금지, 외부 요청 0건
- `tasks.json` 문장은 인쇄본과 한 글자도 달라지면 안 된다는 것

이 넷 중 하나라도 모르면 저장소를 제대로 안 읽은 것이다.
