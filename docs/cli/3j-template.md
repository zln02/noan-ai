# 3단계 (j) — 덱 레이아웃을 템플릿 기준으로

첨부 `템플릿 1.pdf` (미리캔버스 교육용 템플릿, 8쪽) 를 기준으로 **24장의 레이아웃을 바꾼다.**
**원고·순서·id·data-t 는 한 글자도 안 바꾼다.** 바꾸는 건 `shared/deck.css` · `shared/tokens.css` · HTML의 class 뿐이다.

## 0. 색은 안 바꾼다 — 먼저 읽어라

템플릿은 보라(#6C63FF 계열) + 시안 민트다. **우리는 안 따라간다.**
노안중 교색이 녹색이고, 인쇄본 표지에 "이 안내서의 색은 우리 학교 교색에서 가져왔습니다" 가 박혀 있다.
덱만 보라로 바꾸면 종이와 화면이 다른 학교 것처럼 보인다.

→ **`tokens.css` 의 색은 그대로.** 템플릿의 보라 자리에 `--ink`/`--mint`, 시안 자리에 `--mint2` 를 넣는다.
진영님이 "보라로 가자" 고 따로 말하면 그때 토큰 세 개만 바꾼다. 지금은 아니다.

## 1. 템플릿에서 가져오는 것 — 구조 8가지

| 템플릿 쪽 | 패턴 | 우리 덱 어디 |
|---|---|---|
| p1 표지 | 왼쪽 큰 제목(두 굵기 섞음) + 부제 / 오른쪽 원형 배경 위 그림 / **하단 띠: 강사 · 일시 · 장소** | s1 |
| p2 목차 | 왼쪽 「목차」 대형 / 번호 + 항목 + 점선 리더 + 쪽번호 / 오른쪽 그림 | s2 (목차 장) |

## 2. 가져오지 않는 것

- **템플릿의 3D 그림(로봇·구체·원자·눈알·손)과 사진 전부.** 미리캔버스 라이선스 — 결과물은 소속 학교 교육용 한정인데 저장소가 공개다. **파일로 넣지 마라.** 그 자리엔 노아리(`assets/noari/`) 또는 빈 원형 배경만.
- 템플릿 글꼴. 시스템 폰트 스택 유지. 웹폰트 로드 금지 (외부 요청 0건).
- **`PRAT` 표기 — 템플릿 오타다. `PART` 로 쓴다.**
- p4의 「AI란 무엇인가」 식 정의 문장 — 우리 원고에 없고, 넣지 않는다.

## 3. 시각 규칙 — 템플릿에서 뽑은 것

```
바탕        아주 옅은 회색빛      → --paper 유지 (#F6F9F8)
카드        흰색, 모서리 24px, 그림자 0 8px 24px rgba(0,0,0,.06)
구분선      1px, --line
PART 알약   세로 60×110px, 모서리 16px, 배경 --ink, 글자 흰색. 「PART」 작게 위, 「01」 크게 아래
제목        48px. 앞부분 weight 300, 강조부 weight 800. 색 --ink
본문        18~20px, 줄간 1.6
뱃지        알약, 배경 --mint, 흰 글자, 14px
번호 원     28px, --ink 배경, 흰 숫자
발 문구     14px, --mute, 가운데
```

**표지·마무리(s1·s24)는 지금처럼 딥그린 배경 유지.** 템플릿 표지는 흰 카드지만, 우리 덱은 여닫는 장이 어두워야 앞뒤가 잡힌다. 템플릿의 **하단 띠(강사·일시·장소)** 만 가져와서 s1 아래에 넣는다 — 내용은 `박진영 ｜ 2026.09.07(월) 13:00 ｜ 노안중학교`.

## 4. 노아리 자리 (3(i)와 합친다)

| 장 | 파일 | 자리 |
|---|---|---|
| s1 | `noari-flag` | 오른쪽 원형 배경 위 (템플릿 로봇 자리) |
| s2 목차 | `noari-read` | 오른쪽 (템플릿 원자 자리) |

본문(s3~s23)엔 안 넣는다. 움직임은 3(i) 2절의 CSS 세 겹.

## 5. 검증

1. **24장 전부 1280×720 한 화면.** 스크린샷을 `docs/shots/` 에. 넘치는 장이 하나라도 있으면 **커밋하지 마라**, 장 번호를 보고해라.
2. 프로젝터 모드(P)에서 카드 그림자·옅은 배경이 흰색으로 뭉개지지 않는지
3. 다크모드 s3·s12
4. `grep -rn "PRAT" .` → 0건
5. 외부 요청 0건 · `assets/` 에 템플릿 그림 파일 0건 · `private/` 0건
