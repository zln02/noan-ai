# 3단계 (f-1) — 안내서 정정 : 화면 너비

3단계(f)에 준 `tasks.json` 을 **새 파일로 교체해라.** 인쇄본 PDF도 새로 준다.

## 0. 왜

내가 아이모두를 **960px 폭**으로만 보고 안내서를 썼다. **1280px(교무실 모니터 폭)에서 화면이 다르다.**

| | 960px | 1280px |
|---|---|---|
| 도구모음 | 3×2 = **여섯 개** · 화살표 ▶ 필요 | 4×3 = **열두 개** · 첫 화면에 다 보임 |
| 미리캔버스·캔바·패들렛·퀴즈앤·유레카·JNE GPT | 2쪽에 있음 | **1쪽에 이미 있음** |

즉 **“화살표 ▶ 를 누르셔야 합니다” 가 넓은 화면에서는 틀린 안내다.**
교무실 모니터에서 안내서대로 화살표를 누르면 오히려 도구가 사라진다.

## 1. 바꾼 것

**(가) 길찾기에서 ▶ 를 뺐다** — 5장(`01 05 05b 07 12`)

```
전:  [ 도구모음 ▶ > JNE GPT > 전남교육전용 > 가정통신문 생성 도우미 ]
후:  [ 도구모음 > JNE GPT > 전남교육전용 > 가정통신문 생성 도우미 ]
```

**(나) `meta.tip` 을 새로 넣었다** — 두 너비를 한 문장으로 덮는다

> **도구가 안 보이실 때** — 도구모음에 보이는 개수는 화면 너비에 따라 다릅니다.
> 넓은 모니터에서는 열두 개가 한 번에, 노트북·좁은 화면에서는 여섯 개만 보입니다.
> 찾으시는 도구가 없으면 도구모음 오른쪽 화살표 ▶ 를 한 번 누르십시오.

인쇄본에서는 목차(2쪽) 제목 바로 아래 민트 띠로 들어간다.

## 2. 웹에서 할 일

1. `guide/tasks.json` 을 새 파일로 **교체**하고 `tools/sync-data.js` 를 다시 돌려 `guide/tasks.js` 를 맞춰라.
2. `guide/index.html` 첫 화면, **검색창 바로 아래**에 `META.tip` 을 같은 민트 띠로 띄워라.
   - 인쇄본 CSS와 같은 모양: `background:#F1F8F5`, 왼쪽 `4px solid var(--mint)`, 제목 「도구가 안 보이실 때」를 굵게 앞에 붙임.
   - **`tasks.json` 에서 읽어라.** HTML에 문장을 박지 마라.
3. `guide/노안중_AI안내서.pdf` 를 새 파일로 교체. 18쪽 그대로다.

## 3. 사이트 다른 곳도 확인해라

`grep -rn "여섯 개\|화살표를 한 번\|한 번에 여섯" .` 으로 훑고, **덱과 랜딩에 같은 문장이 있으면**
위 `tip` 문장으로 바꿔라. 없으면 아무것도 하지 마라 — 새로 넣지는 마라.

취소본 `guide/slides.json` · `guide/build.py` · `guide/guide.html` 이 저장소에 들어가 있으면
**지워라.** 거기에 “여섯 개만 보입니다” 가 남아 있다.

## 4. 하지 말 것

- `tip` 문장 다듬기 — 인쇄본과 한 글자도 달라지면 안 된다
- 카드 16장·`no`·`title`·`when` 건드리기
- 너비별로 안내서를 두 벌 만들기 — **한 문장으로 덮는 게 목적이다**

## 5. 검증

1. `grep -rn "도구모음 ▶" .` → **0건**
2. `grep -c "▶" guide/tasks.json` → **1건** (`meta.tip` 안의 것 하나)
3. `guide/` 첫 화면에 안내 띠가 뜨는지, `tasks.json` 을 고치면 같이 바뀌는지
4. 인쇄본 PDF 2쪽과 웹 첫 화면 **문장 대조** — 다른 문장 0건
5. 375px에서 띠가 카드를 밀어내지 않는지
6. `node tools/sync-data.js --check` 통과
7. 외부 요청 0건 · `private/` 0건
