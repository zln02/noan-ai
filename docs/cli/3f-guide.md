# 3단계 (f) — 안내서 `guide/` : 업무 카드형

**3단계(e)는 취소한다.** `guide/slides.json`, `tools/guide-build.py`, `tools/guide-print.html`,
`guide/노안중_아이모두_안내서.pdf` 는 만들지 마라. 형식이 바뀌었다.
입력 파일이 안 들어와 있다고 보고한 건 맞다 — 내가 안 넣었다. 이번엔 아래 파일을 함께 준다.

## 0. 왜 바꿨나

도구 순서로 짜면 선생님이 못 찾는다. 선생님은 도구를 찾으러 오는 게 아니라
**“이걸 해야 하는데” 하고** 오신다. 그래서 진입을 **업무 카드**로 바꿨다.

## 1. 받을 파일

| 파일 | 어디에 |
|---|---|
| `tasks.json` | `guide/tasks.json` — **내용의 원본. 문장을 고치지 마라** |
| `노안중_AI안내서.pdf` | `guide/노안중_AI안내서.pdf` (A4 가로 18쪽) |
| `build2.py` | `tools/guide-build.py` — 인쇄본 생성기. 참고용 |
| `qr-guide.svg` `qr-request.svg` | `assets/` |

`tasks.json` 구조: `meta` / `groups`(업무·수업) / `tasks[16]`.
각 task는 `no title when keywords[] tool path[] steps[3] prompt prompt_note shot marks[] caution min[2]`.

`sync-data.js` 의 `PAIRS` 에 추가해 `guide/tasks.js`(`window.GUIDE_TASKS`)를 짝으로 만들어라 —
`file://` 폴백이 필요하다.

## 2. `guide/index.html` — 두 층

### 2-a. 첫 화면 = 카드 그리드

```
무엇을 하시려고요?
[검색창 — 키워드로 찾기]

▸ 업무 · 혼자 하시는 일          (10장)
  00 처음 한 번 — 계정 인증 / 01 가정통신문 쓰기 / …
▸ 수업 · 학생과 함께 하는 일      (6장)
  08b 학생과 쓰기 전에 — 동의서 / 09 우리 학교 AI 캐릭터 만들기 / …
```

- 카드에 `no` · `title` · `when` 만 보여준다. `when` 이 “이럴 때” 문장이라 그게 검색 단서다.
- **검색은 `keywords[]` + `title` + `when` 을 훑는다.** 라이브러리 쓰지 마라. `filter` 한 줄이면 된다.
- 업무는 민트, 수업은 주황 태그.

### 2-b. 카드를 누르면 = 그 업무 한 장

인쇄본의 카드 한 쪽과 같은 배치다.

```
[08b]  학생과 쓰기 전에 — 동의서          [수업]
                        학생 계정을 만들려는데 뭐가 필요한지 모르겠습니다
[ 학교관리자 > 학생 등록 ]
① ② ③ 세 단계
┌ 그대로 붙여넣으세요 ─────────┐   ┌ 화면 캡처 ────┐
│ 프롬프트 (검은 배경)          │   │ (빨간 표시)   │
└──────────────────────────────┘   └───────────────┘
[주의 — 빨간 박스]
보통 40분 → 12분
```

- **프롬프트 박스에 「복사」 버튼**을 달아라. `navigator.clipboard.writeText`.
  실패하면(구형 브라우저·`file://`) 텍스트를 선택 상태로 만들어 주고 “Ctrl+C” 안내를 띄운다.
  이게 이 페이지에서 제일 많이 눌릴 버튼이다.
- `prompt` 가 `null` 이면 프롬프트 박스를 만들지 말고 `prompt_note` 를 민트 박스로 보여라.
- `min` 이 `[0,0]` 이면 절감 시간 줄을 아예 빼라.
- `marks` 는 CSS 오버레이. `--red:#D6362F` 를 `tokens.css` 에 추가.
- 캡처 파일은 `assets/guide/<shot>`. 없으면 점선 자리 + 파일명.

### 2-c. 이동

- 카드 → 상세는 **같은 페이지 안에서** 전환해라(해시 `#08b`). 페이지를 나누지 마라 —
  인쇄본 한 부와 대응되는 게 낫고, 오프라인에서도 한 파일이면 된다.
- 상세 위에 `← 목록으로` 와 `이전 / 다음`.
- 브라우저 뒤로가기가 목록으로 돌아가야 한다.

## 3. 페이지 위아래

맨 위: `이 안내서는 종이로도 있습니다. 같은 내용입니다. [ 인쇄용 PDF 내려받기 — A4 가로 18쪽 ]`
그리고 한 줄: **“필요한 쪽만 뽑아 인쇄하셔도 됩니다.”** (18쪽을 다 뽑을 필요 없다는 걸 알려야 한다)

맨 아래: `이 일이 오래 걸려요 → [요청하기]`

## 4. 사이트의 다른 곳도 고쳐라 — 매뉴얼에서 틀린 게 나왔다

`docs/manual-findings.md` 에서 나온 두 가지다. **`library/index.html` 과 `library/approval.json` 에 반영해라.**

| 지금 사이트 | 고칠 것 | 근거 |
|---|---|---|
| Pro 반영 “10~20분” | **“보통 2~5분”** | 미리캔버스 절차 v2.0 p8 |
| 인증 “간편인증 **또는** 공동인증서” | **“간편인증과 공동인증서를 둘 다 등록”** | 인증서 등록절차 v4.0 p5~7 |

두 번째가 중요하다. “또는” 으로 안내하면 절반이 메뉴 이동에서 막힌다.

여기에 매뉴얼에서 새로 나온 것 두 줄도 `library/index.html` 미리캔버스 항목에 넣어라:

- 미리캔버스에서 직접 「가입하기」를 누르면 오류가 납니다. 반드시 아이모두를 거치십시오.
- 두 번째부터는 웨일스페이스(고래 아이콘)로 미리캔버스에 바로 로그인하실 수 있습니다.

- 덱은 건드리지 마라

## 6. 하지 말 것

- `tasks.json` 의 문장 다듬기 — 인쇄본과 한 글자도 달라지면 안 된다
- 프롬프트 문구 고치기 — 선생님이 그대로 복사해 쓰실 문장이다
- 16장을 줄이거나 합치기
- 외부 라이브러리 (검색·복사·라이트박스 전부 직접 짜라)

## 7. 검증

1. 카드 16장, 업무 10 / 수업 6
2. 검색: “공문” → 02, “동의서” → 08b, “Pro” → 05b 가 나오는지
3. **복사 버튼** — 눌러서 실제로 붙여넣기가 되는지. `file://` 에서 실패했을 때의 대체 동작도
4. 인쇄본 PDF와 웹 **문장 대조** — 다른 문장 0건
5. `prompt` 가 없는 카드에 빈 검은 박스가 안 뜨는지 (7장이 그렇다)
6. 375px에서 카드 1열, 상세는 캡처가 먼저
7. 뒤로가기가 목록으로 가는지
8. `library/` 의 “10~20분” 과 “또는” 이 사라졌는지 — `grep` 으로 0건 확인
9. `node tools/sync-data.js --check` 통과
10. 외부 요청 0건 · noindex · alt 전부 · 태그 균형 · `private/` 0건
