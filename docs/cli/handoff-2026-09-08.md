화면은 헤드리스 크롬으로. 저장소 루트에서 `python -m http.server 8811 --bind 127.0.0.1`:

```python
from playwright.sync_api import sync_playwright   # channel="chrome" 이라 브라우저 내려받기 없음
with sync_playwright() as pw:
    b = pw.chromium.launch(channel="chrome", headless=True)
    for w in (390, 768, 1440):
        pg = b.new_page(viewport={"width": w, "height": 900})
        ext, bad = [], []
        pg.on("request", lambda r: ext.append(r.url)
              if not r.url.startswith(("http://127.0.0.1:8811", "data:", "blob:")) else None)
        pg.on("response", lambda r: bad.append((r.status, r.url)) if r.status >= 400 else None)
        pg.on("pageerror", lambda e: bad.append(("JS", str(e))))
        pg.goto("http://127.0.0.1:8811/index.html", wait_until="load")
        pg.wait_for_timeout(1000)
        # 등장 애니메이션 때문에 한 번 끝까지 굴린 뒤에 찍는다
        pg.evaluate("""async ()=>{for(let y=0;y<document.body.scrollHeight;y+=400){
            window.scrollTo(0,y); await new Promise(r=>setTimeout(r,40));} window.scrollTo(0,0);}""")
        pg.wait_for_timeout(500)
        print(w, pg.evaluate("()=>document.documentElement.scrollWidth-document.documentElement.clientWidth"), ext, bad)
```

**함정 셋 — 여기 이미 걸렸다.**
- 화면 밖 요소는 레이아웃이 안 잡혀 크기가 0 으로 나온다. **한 쪽씩 실제로 띄워서** 재라
- 카드에 등장 애니메이션이 있어 굴리지 않고 찍으면 빈 화면으로 찍힌다
- CSS 중괄호가 한 개만 어긋나도 그 뒤 미디어 쿼리가 전부 죽는다. 고친 뒤 여는 괄호와
