# 고객 여정 지도 (선생님 → 안내서 사이트)

> 이 사이트의 핵심 약속: **연수에서 배운 건 잊어도, 여기 와서 보고 하면 된다.**
> 선생님은 아이모두(ai.jne.kr)에서 일한다. 이 사이트는 그 일을 대신 해 주지 않고, **어디를 누를지와 복사해 붙일 지시서**를 대신 기억해 준다.

## 한 줄 흐름 (모든 순간의 중심)

`업무 찾기` → `해당 안내서 카드` → `아이모두에서 어디를 누르는지(단계)` → `지시서 복사(한 번 누르기)` → `주의사항`

## 사람들

| | AI 처음인 담임 | 바쁜 교과 교사 | 정보부장 · 관리자 |
|---|---|---|---|
| 상황 | 연수에서 들었지만 혼자 하면 막막하다. 폰으로 QR을 찍어 들어온다 | 수업·평가 자료를 빨리 만들고 싶다. 쉬는 10분에 PC로 연다 | 교사 12명이 쓰게 만들어야 한다. 규칙·승인·통계가 궁금하다 |
| 목표 | 가정통신문·회의록을 덜 헤매고 끝낸다 | 문항·활동지·지도안 초안을 바로 받는다 | 어떤 도구가 허용되는지, 누가 막혔는지 안다 |
| 두려움 | 잘못 누르면 어쩌지, 개인정보가 나가면 어쩌지 | 설명이 길면 안 읽는다 | 규정 위반, 질문이 한꺼번에 몰림 |
| 기대하는 것 | 따라 하기만 하면 되는 번호 | 복사 → 붙여넣기 | 근거가 있는 한 장 |

## 시간대별 지도

### 1. 연수 전 — QR로 들어와 준비한다
| | |
|---|---|
| 목표 | 연수 당일 헤매지 않게 로그인과 인증을 끝내 둔다 |
| 행동 | QR 스캔 → 홈 → 「처음 한 번 — 인증」(카드 00) → 아이모두 열기 → 「홈 화면에 추가」 |
| 고민 | 인증서·간편인증을 둘 다 등록해야 하는데 하나만 하고 막힘. QR을 찍었더니 PC용 화면 |
| 기회 | 홈 바로가기에 「처음 한 번 — 인증」을 상단 고정 · 폰 첫 화면이 앱처럼 열림 · 설치하면 오프라인 |

### 2. 연수 중 — 화면을 보며 따라 한다
| | |
|---|---|
| 목표 | 강사 화면과 내 화면을 번갈아 보며 같은 걸 한다 |
| 행동 | 강사가 「04 회의록」 말함 → 번호로 검색 → 단계 1~5를 따라 누름 → 지시서 복사 → 붙여넣기 |
| 고민 | 강당 와이파이가 느리거나 끊김 · 폰 화면이 작아 단계와 지시서가 멀다 · 어디서 이어 가는지 잃어버림 |
| 기회 | 외부 요청 0건이라 가볍다 · 단계 안에 지시서가 바로 들어 있다 · 이전/다음 카드 · 연수 자료는 연수 탭에 같은 순서로 |

### 3. 연수 후 — 일하다 필요할 때 찾는다
| | |
|---|---|
| 목표 | 한 달 뒤에도 「그거 어떻게 했더라」를 30초 안에 해결한다 |
| 행동 | 홈 화면 아이콘 → 검색(「공문」「설문」) → 카드 → 지시서 복사 → 아이모두로 이동 |
| 고민 | 어떤 말로 검색할지 모름 · 지시서의 빈칸을 안 바꾸고 붙여 넣음 · 찾는 카드가 없음 |
| 기회 | 업무 이름 + 동의어 검색 · 지시서의 [빈칸]을 노랗게 표시하고 「이 부분만 바꾸세요」 · 없으면 「요청하기」 · 「도움 됐어요」로 좋은 지시서가 올라옴(선택 기능) |

## 단계별 감정 (요약)

`연수 전: 불안` → `연수 중: 따라가는 중` → `연수 후: 급함` — 그래서 홈의 첫 화면은 설명이 아니라 **검색창과 바로가기**여야 한다.

## 이 지도에서 나온 설계 결정

1. 홈 = 검색 + 4개 바로가기(아이모두 열기 · 인증 · 완전 정복 · 요청). 소개 문구는 한 줄.
2. 카드는 25장 전부를 한 목록에 보이고(숨은 「전체 보기」 제거) 분류 칩으로 좁힌다.
3. 지시서는 카드의 1급 구성요소: 복사 버튼 · 바꿀 곳 표시 · 복사 직후 「붙여넣는 법」 한 줄.
4. 폰은 아래 탭바(홈·아이모두·AI 알기·연수·자료·도움), PC는 위 메뉴.
5. 한 번 본 화면은 오프라인에서도 열린다 (서비스 워커).
