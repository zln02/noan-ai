# 사이트 전체 검토와 손질 (2026-11-20, `fable/review`)

브랜치 `fable/review` (origin/main `f53a511`에서 시작). **main에는 합치지도, 올리지도 않았다.**
그림: [`fable-review-sheet.png`](fable-review-sheet.png) (폰 390px · PC 1440px, 바뀐 쪽만)

## 결론 먼저

1. **사이트의 뼈대는 좋다. 고칠 것은 「말」이었다.** 화면·속도·오프라인은 이미 탄탄하다(검사 26쪽 모두 오류 0, 외부 요청 0). 선생님을 헷갈리게 한 것은 디자인이 아니라 「모델 = 요리사」 같은 **낱말 짝짓기**였다.
2. **AI 알기 16편을 연수와 같은 말로 맞췄다.** 「모델」 → ChatGPT·Claude·AI, 「요리사」 → 요리 로봇(그림 속 주인공은 원래 로봇이었다), 하네스 = **「AI에게 도구와 레시피를 주는 것」**. 주방 그림은 버리지 않았다. 연수의 김치볶음밥 이야기와 같은 세계라서 오히려 이어진다.
3. **연수 자료 2회차의 대표 자료를 새 발표자료(deck-v2)로 바꿨다.** 예전 발표자료는 지우지 않고 「이전 버전」으로 내렸다.
4. **「준비 중」이던 설치·시작 가이드를 실제 내용으로 채웠다.** 첫 화면에서 바로 이어지는 쪽이 빈 쪽이었다.
5. **AI 말 복습 게임(`testbed/ai-quiz`)은 이번에 가져오지 않았다.** 이유는 아래 「복습 게임」 참고.

제품 디자이너와 글 편집자의 눈으로 처음 온 선생님의 길(QR → 첫 화면 → 안내서 → AI 알기 → 연수 자료)을 따라가며 봤다. 「고침」은 이번 브랜치에서 고친 것.

잘 되어 있어서 건드리지 않은 것: 첫 화면의 찾기·찜, 아이모두 완전 정복의 네 칸 구조, 파스텔 카드와 로봇 그림의 분위기, 오프라인 설치, 「확인한 날」 표시. **「미니멀」로 바꾸지 않았다.** 색·그림·말투는 그대로다.

## 바꾼 것

### 1. AI 알기 16편 (말 맞추기)
- 원본 `data/terms.json`만 고치고 `gen-terms.js` → `sync-data.js` → `shoot-terms.py`로 그림 17개와 대표 그림을 다시 만들었다.
- 첫 편 제목 「모델」 → **「ChatGPT·Claude」**. 「모델」이라는 말은 「진짜」 줄에서 한 번만 풀이한다(「흔히 줄여서 모델이라고 불러요」).
- 그림 속 꼬리표 「모델 = 손맛 익힌 요리사」 → 「많이 맛보고 익힌 손맛」. 그림 속 상자 「모델」 → 「AI」.
- 하네스 편: 「주방 한 벌」 → **「도구와 레시피」**, 한 줄 정리 **「하네스 = AI에게 도구와 레시피를 주는 것」**, 비유 줄은 김치볶음밥 이야기 그대로.
- **비유를 뺀 편 2개**: 멀티모달(「사진 주문 알아듣는 요리사」), 학생 지도(「칼 쓰는 실습」). 비유가 뜻을 더해 주지 않았다. 카드에서 비유 줄이 사라지고 「비유와 다른 점」은 「주의할 점」이 된다. 나머지 14편은 비유 → 진짜 → 활용을 그대로 둔다(김밥 썰기·조리대·오픈북 시험처럼 잘 맞는 것들).
- 이를 위해 `terms.json`에 선택 칸 3개를 더했다: `scene_label` `real_label` `gap_label`. 안 적으면 예전과 똑같이 나온다.
- 비유 지도 `docs/content/analogy-map.md`의 표도 새 글로 다시 만들었다.

### 2. 연수 자료 2회차
- 대표 자료: **`training/s2-deck-v2.html`** (「AI에게 무기를 주면」, 34장). teacher-studio의 `docs/training/deck-v2.html`을 그대로 복사하고 **머리 부분 세 줄만** 더했다: 폰 화면 맞춤(`minimum-scale=1`), 사이트 아이콘, 검색 제외(`noindex`). 원본을 새로 복사할 때 이 세 줄을 다시 넣어야 한다. 함께 들어간 남의 코드·글꼴 목록은 `training/s2-deck-v2-NOTICE.md`.
- **크기 7.7MB.** 3D 그림과 글꼴이 파일 안에 다 들어 있어서 크다. 그래서 **미리 담기 목록(`sw.js`)에서 뺐다.** 넣으면 사이트를 처음 여는 모든 선생님이 7.7MB를 받게 된다. 지금은 발표자료를 한 번 열면 그때 담기고, 그다음부터는 인터넷 없이 열린다. **연수 전날 강당 컴퓨터에서 한 번 열어 두면 된다.** 캐시 이름은 `v7` → `v9` (`v8`은 복습 게임 브랜치가 쓰고 있어 건너뜀).
- **예전 발표자료(`s2-deck.html`)는 「이전 버전」으로 남겼다.** 지우지 않은 이유: 도구 아홉 가지를 한 줄씩 보여 주는 장은 새 자료에 없고, 이미 공유된 주소가 죽으면 안 된다. 대신 맨 아래로 내리고 흐린 점선 카드로 구분했다. 3번 장의 「실력 좋은 요리사」는 「솜씨 좋은 요리 로봇」으로 바꿨다. 미리 담기에서도 뺐다(77KB라 부담은 없지만 대표 자료가 아니므로).
- 20초 영상 실습 안내와 PPTX는 「함께 보는 실습」으로 그대로 있다. **2회차 제목을 「AI에게 무기를 주면」으로 바꿨는데, 영상 실습을 2회차에 계속 둘지는 정해 주셔야 한다.**
- 대표 자료 단추만 파란색으로 해서 무엇부터 누를지 보이게 했다.

### 3. 설치·시작 가이드 (`start/`)
- 발표자료의 실습 1~3을 글로 옮겼다: AI 고르기 → 컴퓨터를 쓰는 모드로 열기 → 링크 붙여 넣고 한 줄. 이어서 첫 부탁 예시 3개와 꿀팁 3줄.
- 발표자료에 있는 내용만 적었다. 앱 단추 이름은 직접 확인하지 못해 쪽에 「확인 필요」라고 적어 두었다.
- 첫 화면 카드의 「(준비 중)」을 지웠다.

### 4. 작은 손질
- `training/s2.html`: 낱말 중간 줄바꿈 막기, 폰에서 제목 크기 한 단계 줄임.
- AI 알기 16편: 묶음 3개로 건너뛰는 단추.
- 첫 화면 카드 「AI 알기」 → 「AI 활용 안내」(쪽 제목과 같게).
- 수업 도구(`studio/`)는 건드리지 않았다.

## 복습 게임(`testbed/ai-quiz`)을 가져오지 않은 이유

게임 자체는 잘 돌아간다(오류 0, 외부 요청 0). 그래도 지금 합치지 않는다.

1. **문제 글이 옛 말이다.** 8문제 중 2문제가 「모델」을 정답·보기로 쓴다. 이번에 사이트에서 뺀 바로 그 말이다.
2. **폰 세로에서 읽기 어렵다.** 「폰으로 2분」이 목적인데 화면을 90° 돌려서 보여 주고, 해설 글자가 약 10px이고, 확대도 막혀 있다(그 브랜치의 기록 F1·F13·F14에 스스로 적혀 있다).
3. **이 브랜치의 진짜 값은 게임이 아니라 기록이다.** `docs/harness-testbed/2026-11-ai-quiz.md`는 하네스를 고칠 사람이 읽는 글이고, 사이트를 보는 선생님과는 상관이 없다.

권장: 하네스 쪽에서 F1(폰 세로)·F2(글꼴 링크)가 고쳐진 뒤, 새 `terms.json` 글로 문제를 다시 뽑아 다시 만든다. 브랜치는 그대로 두었다.

## 확인한 것

헤드리스 크롬 한 개로, 15쪽 × 폭 5가지(320·390·768·1024·1440px) + 「동작 줄이기」 켠 폰 15쪽 = **90번** 열어 봤다. 대상: 첫 화면, 연수 자료, 2회차 실습 안내, 예전·새 발표자료, 설치·시작 가이드, AI 알기 16편, AI 활용 안내, AI는 어떻게 답을 만들까, 아이모두, 도움, 움직이는 그림 4편.

| 항목 | 결과 |
|---|---|
| 외부 요청 | **0건** (90번 모두) |
| 콘솔 오류 | **0건.** 단, 움직이는 그림 파일을 주소로 **직접** 열면 브라우저가 찾는 기본 아이콘이 없어 404 한 줄이 뜬다. 원래부터 그랬고 카드 안에서 재생할 때는 안 뜬다 |
| 가로 넘침 (320~1440px) | **0건** |
| 화면 밖으로 나간 요소 | **0건** |
| axe 「심각」 이상 | **0건** (390·1440px과 동작 줄이기 상태에서 검사) |
| 동작 줄이기 | 15쪽 모두 오류·넘침 없음. 움직이는 그림은 장면마다 멈춘 그림으로 넘어간다(원래 기능) |
| 새 발표자료 폰 화면 | 세로·가로 모두 한 화면에 맞게 들어옴 (고치기 전에는 왼쪽 일부만 보였다) |
| JSON·JS 짝 | `node tools/sync-data.js --check` 통과 |

고치는 중에 잡은 것 두 가지: 설치·시작 가이드가 320px에서 5px 넘치던 것, 「덱 열기」 파란 단추의 글자색 대비 부족(1.62:1 → 흰 글자 5.3:1).

검사 도구가 모든 쪽에서 머리글의 「아이모두 바로가기」 단추를 「글자 잘림」으로 표시했는데, 단추 위를 지나가는 반짝임 장식 때문에 나온 잘못된 경보다. 화면에서 글자는 다 보인다(그림 참고).

눈으로 확인하지 않은 것: 실제 폰 기기, 실제 강당 프로젝터, GitHub Pages에 올라간 뒤의 서비스 워커 갱신(캐시 `v9`로 바뀌는지).

## 남은 것 (다음에 할 순서대로)

1. **teacher-studio 원본 `deck-v2.html` 고치기**: `<meta name="viewport">`에 `minimum-scale=1`이 없으면 폰에서 화면이 잘린다. 원본에서 고치면 사이트 복사본의 덧붙임이 필요 없어진다.
2. **AI 활용 안내의 Claude·ChatGPT 카드 채우기** (공식 안내를 보고 「확인한 날」과 함께).
3. **2회차 구성 정하기**: 하네스 연수와 20초 영상 실습을 한 회차에 둘지 나눌지. 날짜가 정해지면 `data/schedule.json`도.
4. **16편 내용 확인 날짜 적기** (`terms.json`의 `checked`). 지금은 모두 비어 있다.
5. `s2.html`을 사이트 공통 틀(머리글·아래 탭)로 옮기기.
6. 탭 이름 「AI 알기」와 쪽 제목 「AI 활용 안내」 하나로 정하기.
7. 복습 게임 다시 만들기(위 권장대로).
8. 「AI는 어떻게 답을 만들까」의 「AI 주방」 꼬리표는 그대로 두었다. 로봇 이야기와 어긋나지는 않지만, 연수 뒤 반응을 보고 정하면 된다.
