목표: 가정통신문·회의록을 덜 헤매고 · 두려움: 잘못 누를까, 개인정보

목표: 문항·활동지·지도안 초안 · 기대: 복사 → 붙여넣기

정보부장 · 관리자

교사 12명이 쓰게 만들어야 한다.

목표: 허용 도구·막힌 곳 파악 · 기대: 근거가 있는 한 장

세 순간

1. 연수 전QR로 들어와 준비한다
행동
QR 스캔 → 홈 → 인증(카드 00) → 아이모두 열기 → 홈 화면에 추가
고민
인증서·간편인증을 하나만 등록해 막힘 · QR이 PC 화면으로 열림
기회
홈에 「처음 한 번 — 인증」 바로가기 · 앱처럼 열림 · 설치하면 오프라인
2. 연수 중화면을 보며 따라 한다
행동
강사가 「04 회의록」 → 검색 → 단계 1~5 → 지시서 복사 → 붙여넣기
고민
강당 와이파이 · 폰 화면이 작아 단계와 지시서가 멀다 · 이어 갈 곳을 잃음
기회
외부 요청 0건 · 단계 안에 지시서 · 이전/다음 카드 · 연수 자료도 같은 순서
3. 연수 후일하다 필요할 때 찾는다
행동
홈 화면 아이콘 → 「공문」 검색 → 카드 → 지시서 복사 → 아이모두
고민
검색어를 모름 · 빈칸을 안 바꾸고 붙임 · 찾는 카드가 없음
기회
동의어 검색 · [빈칸] 노랗게 표시 · 없으면 요청하기 · 「도움 됐어요」(선택)
연수 전: 불안연수 중: 따라가는 중연수 후: 급함

그래서 홈 첫 화면은 설명이 아니라 검색창과 바로가기다.
