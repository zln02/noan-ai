## 결론 먼저

1. **처음 보이는 글자가 쪽마다 11~27% 줄었어요.** 안내서 카드 25장은 합계 **17,446 → 12,073자(−31%)**.
2. **모든 쪽 맨 위에 「이 페이지에서 할 수 있는 것」 세 줄**을 넣었어요 (번호 + 굵은 낱말 + 짧은 한 줄).
3. **문장 → 굵은 라벨 + 한 줄.** 안내서 카드는 칩 한 줄(도구 · 시간 · 단계)과 한눈에 **4칸(무엇을 · 어디서 · 어떻게 · 주의)**, 도구 사전 줄도 같은 4칸.
4. **긴 설명은 「더 보기」(`<details>`)로 접었어요.** 근거·확인한 날, 결과 예시, 긴 주의, 진짜 더, 키 표, 「안 되면」.
5. **사실은 그대로.** 숫자·단추 이름·단계 수·전화번호·날짜는 하나도 안 바꾸고 말만 줄였어요. 지시서(프롬프트) 본문, 움직이는 그림·자막은 안 건드렸어요.
6. 점검: 390·1440px 모두 **넘침 0 · 바깥 요청 0 · axe serious 0 · 콘솔 오류 0**, 내부 링크 67개 중 깨진 것 0(아래 ¹ 하나는 곧 들어올 파일).
