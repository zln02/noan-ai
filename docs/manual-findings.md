# 아이모두 매뉴얼 — 읽고 나서

> `docs/manual/` PDF 34개(1,568쪽)를 읽고 뽑은 것. 어디에 무엇이 있는지는 `manual-index.md`.
> 2026-09-03.

## 1. 판단 — 선생님은 이 매뉴얼을 읽지 않아도 된다

읽지 마시라고 말씀드려도 된다. 근거가 셋이다.

첫째, **분량이 과업과 안 맞는다.** 교사 매뉴얼 하나가 212쪽이고, 그중 우리 연수와 관계있는 건
로그인·수업도구·학생배정 세 곳, 다 합쳐 20쪽 남짓이다. 나머지는 클래스·수업·과제·토론·꾸러미
저작처럼 10월 이후에나 필요한 것이다.

둘째, **본문이 살아 있는 판은 구버전뿐이다.** 텍스트가 추출되는 매뉴얼은 전부 v4.0 계열이고,
현재 화면에 해당하는 v5.1·v6.1은 전 쪽이 스크린샷이다. 선생님이 최신판을 열면 검색도 복사도 안 된다.

셋째, **선생님이 실제로 막히는 지점을 매뉴얼이 안 다룬다.** 도구가 6개만 보이는 것, 「도구 설정」,
JNE GPT — 이 셋은 어느 매뉴얼에도 없다.

그래서 방향은 이렇다. **매뉴얼을 요약해 드리지 말고, 매뉴얼이 못 다루는 다섯 가지만 우리 안내서로 만든다.**
매뉴얼은 "이런 게 있고 헬프센터에서 받으실 수 있다"고 위치만 알려드린다.

## 2. 선생님이 꼭 알아야 할 것 다섯 개

1. **인증서를 등록하기 전에는 아무 데도 못 간다.**
   2025년 11월 14일부터 바뀌었다. 로그인하면 비밀번호 검증 창이 반복해서 뜨고, 인증서를 등록할 때까지 다른 메뉴로 이동이 막힌다.

2. **간편인증과 공동인증서를 둘 다 등록해야 한다.**
   하나만 해서는 안 된다. 매뉴얼이 "모두 등록하셔야 이용이 가능합니다"라고 두 번 반복한다.

3. **아이디는 이메일 형태이고, 도메인까지 외워야 한다.**
   이 계정이 미리캔버스 같은 연결 도구의 로그인에 그대로 쓰인다. 앞부분만 기억하면 두 번째부터 못 들어간다.

4. **미리캔버스는 절대 "가입하기"로 시작하면 안 된다.**
   교육청 계정으로 미리캔버스에서 직접 가입을 누르면 오류가 난다. 반드시 아이모두 안 수업도구에서 들어간다.

5. **두 번째부터는 미리캔버스에서 바로 로그인해도 된다 — 단 웨일스페이스로.**
   miricanvas.com에서 [로그인] → 고래 아이콘(웨일스페이스) → 아이모두 아이디. 이 경로를 모르면 매번 아이모두를 거친다.

## 3. 매뉴얼이 어렵게 설명한 것

| 매뉴얼 표현 | 우리 안내서에서는 |
|---|---|
| "간편인증(민간인증서) + 공인인증서(EPKI) 인증 절차 적용" | "카카오·통신사 인증 **하나**, 학교에서 쓰시는 공동인증서 **하나** — 둘 다 등록하셔야 넘어갑니다" |
| "인증서를 등록하지 않았을 시 반복적으로 본 화면으로 이동하며" | "비밀번호 창이 계속 뜨면 고장이 아닙니다. 인증서를 아직 안 넣으신 겁니다" |
| "포털 메인화면의 수업진행현황 아래의 수업 도구 영역에서 아이콘을 클릭" | "아이모두 첫 화면을 **아래로 내리면** 도구 아이콘들이 있습니다" |
| "[설정 > 결제 정보 설정] 영역에 Pro 요금제가 적용되었는지 확인" | "오른쪽 위 내 이름 → 워크스페이스 → 설정에서 **Pro**라고 쓰여 있으면 된 겁니다" |
| "콘텐츠들을 교육과정 기준으로 수업꾸러미로 만들고" | "**수업꾸러미 = 한 차시에 쓸 자료 묶음**입니다. 남이 만든 걸 가져와 고쳐 쓰는 게 제일 빠릅니다" |
| "학생 개인정보 활용 동의서를 PDF로 첨부합니다" | "학생 계정은 **동의서 종이가 먼저**입니다. 양식은 제가 교육청에 받아 드리겠습니다" |

## 4. 매뉴얼과 우리 사이트가 다른 곳 — 고쳐야 한다

**이게 이번 분석에서 제일 값나가는 부분이다.** 둘 다 우리 쪽이 틀렸다.

| 항목 | 우리 사이트 (현재) | 매뉴얼 | 조치 |
|---|---|---|---|
| 미리캔버스 Pro 반영 시간 | "10~20분 뒤 자동 적용" | **"회원가입 후 약 2~5분 후 적용"** (미리캔버스 절차 v2.0 p8) | 2~5분으로 고칠 것. 연수 중 실습이면 이 차이가 크다 |
| 교사 인증 방식 | "본인인증(간편인증 **또는** 공동인증서) 등록" | **둘 다 등록해야 함** (인증서 등록절차 v4.0 p5~7) | "또는"을 "둘 다"로. 이대로 두면 절반이 막힌다 |

같이 넣으면 좋을, 우리가 아직 안 쓴 사실:

- 미리캔버스에서 **직접 가입하면 오류**가 난다는 경고 (매뉴얼 1쪽·3쪽·9쪽에 세 번 반복된다)
- 두 번째부터의 **웨일스페이스 로그인 경로**
- Pro 확인 위치가 [설정 > 결제 정보 설정] 이라는 것 (우리는 이미 적어 뒀다 — 매뉴얼과 일치)
- 회원가입 후 **학교관리자 승인**이 나야 쓸 수 있고, 승인되면 문자가 온다는 것

한편 우리가 맞게 쓴 것: 아이모두 주소 `ai.jne.kr`(학생 매뉴얼 v4.0 p4의 시도교육청 표와 일치),
수업도구에서 미리캔버스로 들어가는 경로, Pro 확인 위치.

## 5. 학생 계정 — 되는 것 / 안 되는 것 / 안 나온 것

**되는 것**
- 학생 계정은 **학교관리자 또는 교사**가 만든다 (교사 회원가입 가이드 p4). 학생이 스스로 가입하지 않는다.
- 개별 등록(학교관리자 v4.2 p14)과 **일괄 등록**(p17) 둘 다 있다. 일괄 등록 양식은 화면에서 내려받는다.
- 교사가 학생 비밀번호를 바꿔 줄 수 있다. 개별(교사 매뉴얼 v4.0 p157~158)·**일괄**(p159) 모두.
  바꿀 때 **선생님 본인 비밀번호를 먼저 넣는다.**
- 학생이 쓰는 화면은 넷뿐이다 — 나의 수업 / 사이드바 / 학습 기록 / 헬프센터 (학생 중등 v4.0 p2).

**안 되는 것 · 조건이 붙는 것**
- **학생 개인정보 활용 동의서 PDF를 첨부해야 계정이 만들어진다.** 양식은 교육청 담당 장학사에게 받는다.
  → 우리가 "학생 계정은 학교 확인 필요"라고만 써 둔 것의 실체가 이것이다. **동의서 양식 확보가 10월 수업의 첫 단추다.**
- 방과후에 쓰려면 **학교관리자가 과목에 "방과후"를 먼저 추가**해야 교사가 클래스를 만들 수 있다 (방과후 v4.1 p3~4).
- 구글 클래스룸 연결은 **수업도구에서 먼저 로그인**해 두지 않으면 오류가 나고, 연결 완료까지
  **수 분~수 시간**이 걸린다 (교사 매뉴얼 v4.0 p35). 수업 당일에 하면 안 된다.

**매뉴얼에 안 나온 것**
- 학생 계정으로 **어떤 수업도구까지 쓸 수 있는지** 목록이 없다. 교사 화면 기준으로만 설명한다.
- 만 14세 미만 처리에 대한 언급이 없다. 동의서 양식에 있을 것으로 보이나 매뉴얼로는 확인 불가.
- 학생이 미리캔버스를 쓸 수 있는지 — **없음**.

**하지 말 것으로 정한 것**: 매뉴얼 요약본을 따로 만들지 않는다. 212쪽을 4쪽으로 줄여도
선생님은 안 읽는다. 위 여덟 줄이 실제로 필요한 전부다.

## 부기 — 개인정보

- 학교 관리자 매뉴얼 v4.2 p14·p17 은 학생 등록 화면이라 **예시에 개인정보 항목이 나온다.**
  이름·생년월일·성별·학년·반·번호·보호자 연락처. 값은 옮기지 않았다.
- 스크린샷만 있는 17개 파일은 열어보지 않았으므로, **그 안에 예시 개인정보가 있는지 확인되지 않았다.**
  사람이 볼 때 이 점을 같이 봐 주기 바란다.
