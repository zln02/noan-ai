- 요청: 「AI 알기 용어 복습 게임, 선생님들이 연수 쉬는 시간에 폰으로 2분」
- 결과: `terms/quiz/index.html` (퀴즈 8문제, 445 KB, 외부 요청 0건). `terms/index.html`(AI 알기 16편)의 「이어서 보기」 카드 위에 카드로 연결함
- 다시 만드는 법:
  ```
  py ~/.claude/skills/teacher-game/scripts/build.py --spec docs/harness-testbed/ai-quiz/spec.json --out terms/quiz/index.html
  py docs/harness-testbed/ai-quiz/postbuild.py terms/quiz/index.html
  py ~/.claude/skills/teacher-game/scripts/check_game.py terms/quiz/index.html
  ```
  (`spec.json`에 `design.seed: 93150`을 고정해 두어서 모양이 똑같이 나온다.)
- 점검: `check_game` **PASS (실패 0 · 주의 0)**. postbuild를 거친 뒤 파일 기준. `design_review` PASS. 사이트 쪽: 카드 겹침 0, 가로 스크롤 없음(390px·1366px), AI 알기 페이지 외부 요청 0
- 그림: `docs/ux/testbed-ai-quiz-sheet.png` (PC 화면 6개, 폰 세로 3개, 폰 가로 2개, 진입 카드 PC·폰)

## 거친 순서 (실제로 한 일)
1. 라우터: `teacher-studio/SKILL.md` R0~R4 → `direction.py` 실행 → `mode: build_now` → R4 → teacher-game 「직접 제작」(spec). 아래 F8 참고
2. `color_from.py shared/premium.css` → `palette.json` (주색 #1568d2, 사이트 브랜드색과 같음)
3. `style_auto.py`·`layout_auto.py`로 미리 보기 → spec 작성 → `build.py` → `check_game` → `design_review` → 접촉 시트를 직접 봄
4. 디자인 4바퀴. 1바퀴: 네온 격자에 과학 소품, 「밤티」. 2바퀴: style 고정, 세리프에 회색 비네트. 3바퀴: 고딕, 3칸 타일이라 줄바꿈이 깨짐. 4바퀴: split+pill, 비네트 끄기, 사이트 파스텔 장식 → 채택
5. 하네스가 표현하지 못한 것은 `postbuild.py`에서 고침(아래 「손으로 고친 것」)
6. 사이트 연결: 카드, `sw.js` 미리 담기 목록과 캐시 버전(v7→v8)

## 잘 된 것
- **check_game이 폭넓다.** 번쩍임(WCAG 2.3.1), 동작 줄이기, 효과 줄이기·소리 끄기 스위치, 4배 느린 CPU 30fps, 터치 44px, 색만으로 정오답 구분 금지, 색약 시뮬레이션, ES2017까지 한 번에 확인한다. 사이트 규칙과 거의 겹쳐서 따로 검사할 일이 줄었다.
- **palette_from 연결은 한 번에 됐다.** spec 옆 상대 경로를 알아서 찾고, 주색 #1568d2가 사이트 브랜드색과 정확히 같았다.
- **custom_css·custom_svg 칸이 쓸모 있다.** 사이트 파스텔 점·별, 고딕 글꼴, 비네트 끄기를 하네스 안에서 해결했다. 바깥 주소 금지 같은 안전 장치도 적당했다.
- **seed 고정**으로 같은 모양을 다시 만들 수 있다. spec 오류는 「고칠 곳」으로 바로 알려 준다.
- **엔진 블록 보존 검사** 덕분에 손으로 고치는 범위가 분명했다(엔진 밖에 스크립트 추가). 무대를 돌려도 탭 위치가 맞았다(`NG.center`가 돌아가는 계산이라 그대로 맞음).
- **Game Wow kit**(눌림·파티클·연속 정답·결과 연출)이 자동으로 붙어 손맛이 기본으로 좋다. 동작 줄이기 설정도 따른다.
- `design_review`가 자기 Chrome을 찾아 쓴다(`channel="chrome"`로 넘어감). Playwright 브라우저를 따로 받지 않아도 돌았다.

## 내용 확인 (문제 8개)
모두 `data/terms.json`(checked 항목)의 비유 → 진짜 → 활용에서만 뽑았다: 토큰(김밥 썰기), 모델(다음 말 예측), 맥락 창(새 대화에 핵심만), 환각(속일 뜻 없음, OX), 프롬프트(학습한 글은 안 들어감), 에이전트(되돌리기 어려운 일은 사람이 확인), 자료 붙이기·RAG(자료로만 답하고 쪽수), 개인정보(이름·연락처·성적 빼기). 학생 정보 입력칸·점수 저장 없음.
