# 2회차 교원 연수 — AI로 30초 수업 영상 만들기

**운영안:** 120분, 개인 또는 2인 1조. 날짜와 참여 인원은 추후 확정.

## 연수 목표

선생님 각자가 자기 교과의 개념 도입 또는 학교의 공개 가능한 안내를 주제로 **20~30초, 16:9 MP4 영상 한 편**을 저장한다. 영상에는 3개 장면, 읽을 수 있는 자막, 확인한 사실, 배경음 또는 음성 중 하나가 들어간다.

한 도구로 전부 만들려 하지 않는다. **JNE GPT**에서 대본과 5초 영상 한 장면을 만들고, **미리캔버스**에서 이미지·동영상을 이어 자막과 소리를 붙인 뒤 MP4로 내려받는다. JNE GPT의 AI 비디오 화면은 아이모두 도구모음에서 실제 접근을 확인했다(2026-10-21). 미리캔버스는 [동영상 요소·자막·오디오·MP4 다운로드](https://help.miricanvas.com/hc/ko/articles/32570677518617-%EB%8B%A4%EC%9A%B4%EB%A1%9C%EB%93%9C-%EA%B0%80%EC%9D%B4%EB%93%9C)를 지원한다.

## 120분 시간표

| 시간 | 활동 | 선생님이 남기는 것 |
|---|---|---|
| 0–10분 | 완성 예시 1편 보기, 결과 기준 확인 | 만들 주제 1개 |
| 10–25분 | JNE GPT로 3장면 대본 초안 작성·사실 확인 | 장면·자막·소리 계획표 |
| 25–50분 | JNE GPT 비디오에서 5초 장면 1개 생성 | MP4 클립 1개 |
| 50–60분 | 생성 결과 검토·교체, 필요하면 예비 클립 사용 | 사용할 장면 3개 확정 |
| 60–90분 | 미리캔버스에서 장면 순서·길이·화면 비율 편집 | 20~30초 영상 초안 |
| 90–105분 | 자막 직접 수정, 배경음 또는 음성 추가 | 소리 없이 봐도 이해되는 영상 |
| 105–115분 | MP4 다운로드·재생 확인 | 재생되는 최종 파일 |
| 115–120분 | 짝과 교차 확인·수업 적용 메모 | 바꿀 점 1개 |

**실습 비율:** 설명·시연 20분, 직접 제작·검토 100분을 목표로 한다. 강사는 각 단계에서 2~3분만 보여 주고 즉시 참가자가 따라 하게 한다.

## 실습 주제와 완성 기준

권장 주제는 “다음 수업의 개념 하나를 여는 30초 영상”이다. 예: 과학 단원 도입, 미술 작품 감상 질문, 학교 도서관 이용 안내. 학교 고유 일정·규정은 확정된 자료가 있을 때만 넣는다. 학생 얼굴·이름·목소리가 들어간 실자료는 이번 연수에서 사용하지 않는다.

완성 기준은 ① 장면 3개 ② 20~30초 ③ 화면에 읽을 수 있는 자막 ④ 사실 오류·개인정보·소리 크기 확인 ⑤ 저장한 MP4를 다시 열어 재생 확인이다. AI 장면이 생성되지 않아도 강사가 준비한 예비 클립 또는 미리캔버스의 움직이는 요소로 완성할 수 있다.

## 복사해서 쓸 요청문

### 1. 장면 기획 — JNE GPT 대화

> 중학교 [학년] [교과]의 [주제]를 여는 25초짜리 수업 영상 대본을 만드세요. 3장면으로 나누고 각 장면의 길이, 화면에 보일 것, 자막 한 줄, 내레이션 한 줄을 표로 적으세요. 학생 얼굴·이름·목소리는 넣지 않습니다. 확인되지 않은 학교 일정이나 수치는 쓰지 말고 [교사 확인]으로 남겨 주세요. 설명은 [학년] 학생이 이해할 말로 써 주세요.

### 2. 5초 장면 — JNE GPT 비디오

> 중학교 수업 도입용 16:9 영상, 5초. 빈 책상 위의 색색 종이 카드 세 장이 천천히 놓이고, 카메라가 부드럽게 오른쪽으로 이동한다. 화면 속 글자·로고·사람 얼굴·음성은 없다. 밝고 차분한 교실 분위기.

글자를 AI 영상 안에서 만들지 말고, 나중에 미리캔버스에서 직접 입력한다. 장면이 마음에 들지 않으면 프롬프트에서 **피사체·동작·카메라 움직임** 중 하나만 바꿔 본다. 시간과 사용 한도를 고려해 개인 실습은 **1회 생성**을 기준으로 준비한다.

## 강사 준비

- 행사 2~3일 전 아이모두 → JNE GPT → 비디오와 미리캔버스가 각 교사 계정에서 열리는지 확인한다. JNE GPT 비디오의 사용 권한·한도·학교 예산 처리 방식은 관리자에게 확인한다. 공급사 안내에는 비디오 생성의 사용량에 따른 비용이 명시돼 있다. [웍스AI 기능 안내](https://docs.wrks.ai/release-notes), [요금표](https://docs.wrks.ai/pricing)
- 예비 5초 클립 2개, 정지 이미지 3개, 완성 MP4 1개를 **가상 정보**로 만들어 USB와 노트북에 저장한다. 참가자가 생성에 실패해도 편집 실습을 계속할 수 있게 한다.
- 참가자에게 개인 노트북 또는 태블릿, 이어폰, 아이모두 로그인, 다운로드 가능한 저장 공간을 안내한다. 가능하면 노트북을 권장한다.
- 교실 와이파이, 프로젝터 소리, 다운로드 후 재생을 미리 확인한다. 화면 공유용 원본 영상은 음량을 낮춘다.
- 배경음은 미리캔버스 제공 요소 또는 사용 권한을 확인한 음원만 사용한다. 가요나 온라인에서 임의로 내려받은 음원은 실습 기본 재료로 두지 않는다.

## 진행 중 확인 질문

1. 10분: 이 영상이 학생에게 남길 질문 한 개는 무엇인가?
2. 50분: AI가 만든 장면에 사실과 다른 것이 있는가?
3. 90분: 소리를 끄고 봐도 이해되는가?
4. 115분: 다운로드한 MP4를 다시 열어 끝까지 재생했는가?
